### ✅ Checklist

#### Obligatorios (O1–O9)

- [ ] **O1** — Estructura semántica (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`, un solo `<h1>`, `alt` en imágenes)
- [ ] **O2** — Tema visual con `@theme` (color de marca con 3+ tonos, acento, tipografía personalizada)
- [ ] **O3** — Cabecera con flexbox (logo izquierda, menú derecha, responsive, `hover:` + `focus-visible:`)
- [ ] **O4** — Hero (título + texto + 2 botones + imagen, stacked en móvil, lado a lado en `md:`)
- [ ] **O5** — Rejilla de tarjetas (6+ tarjetas, `grid-cols-1 sm:grid-cols-2 lg:grid-cols-3`, hover lift, `aspect-video` + `object-cover`)
- [ ] **O6** — Sección de pasos (3 items, `flex-col md:flex-row`, contenido centrado)
- [ ] **O7** — Pie de página (3+ columnas en escritorio, apiladas en móvil, copyright con `border-top`)
- [ ] **O8** — Accesibilidad (navegación por teclado, `focus-visible:`, Lighthouse ≥ 90)
- [ ] **O9** — README + bitácora de IA (este archivo)

#### Opcionales (P1–P7)

- [ ] **P1** — Modo oscuro (`dark:` o toggle con `@custom-variant`)
- [ ] **P2** — Cabecera fija con efecto cristal (`sticky backdrop-blur`)
- [ ] **P3** — Planes con tarjeta destacada (badge con `absolute`)
- [ ] **P4** — FAQ plegable sin JavaScript (`<details>` + `group-open:rotate-180`)
- [ ] **P5** — Formulario con estados (`focus:`, `invalid:`, `peer-invalid:block`)
- [ ] **P6** — Bento grid (`col-span-2 row-span-2`)
- [ ] **P7** — Animaciones con `motion-safe:`

#### Desafíos (D1–D7)

- [ ] **D1** — Menú hamburguesa sin JavaScript
- [ ] **D2** — Container queries (`@container` + `@md:`)
- [ ] **D3** — Multitema vía CSS variables + `[data-theme]`
- [ ] **D4** — Custom `@utility`
- [ ] **D5** — Layout de aplicación con grid areas
- [ ] **D6** — Screenshot → AI code → refine
- [ ] **D7** — Lighthouse 100
